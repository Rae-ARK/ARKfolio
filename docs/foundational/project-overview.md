# Project Overview

ARKfolio is the author site for Rae ARK (嵐久 怜), a web novelist.
Live at <https://rae-ark.horizonarkstudio.workers.dev/>.

## Stack and delivery

Vue 3 + Vite + TypeScript, shipped three ways: as a website, as an
installable PWA, and as a native Android app via Capacitor. The website is
hosted on Cloudflare Workers (static assets with SPA fallback).

## Content model

Works, journal entries and store listings live in `src/data/*.ts`. Updating
the site means editing those files, not page markup.
