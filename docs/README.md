# ARKfolio Docs

Docs are organised by lifecycle stage: where an idea starts, what it
becomes, and what it is now.

| Stage | Question it answers | Index |
| --- | --- | --- |
| **Foundational** | Why does this project exist, and whose voice is it? | [foundational/](foundational/README.md) |
| **Implementation** | What is built today, and how good is it? | [implementation/](implementation/README.md) |
| **Proposals** | What do we intend to change next? | [proposals/](proposals/README.md) |

## How a change moves through the docs

1. A change starts as a file in `proposals/`.
2. Once it ships, its outcome is recorded in `implementation/` and the
   proposal's status is set to `Implemented`.
3. Anything that explains the project's intent or voice (rather than its
   code) lives in `foundational/` and rarely changes.
