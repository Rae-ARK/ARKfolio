## Adding a proposal

Create `NNNN-short-title.md` with a status, the problem, the proposed
change, and open questions. Add it to the table above. Once a proposal is
fully implemented, record its outcome in the changelog and remove the
proposal file — don't let a finished proposal linger as a duplicate of
the changelog entry.
