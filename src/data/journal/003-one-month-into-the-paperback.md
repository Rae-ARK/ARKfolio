The June 2026 paperback edition of Summoned by Mistake, I Decided to Learn How to Live has been out for a few weeks now. It's still a limited print run with lighter formatting, and the web novel isn't going anywhere — SBM was written as a web novel first, and it stays that way, paperback or not.
